# Фото для документов

Бесплатная программа для фотосалона и копицентра. Окно собрано как привычное рабочее место: слева снимки, в центре исходник с рамкой, справа формат и коррекция. Сверху три шага — «Размеры», «Готовые фотографии», «Печать». Снимок остаётся на этом компьютере.

Первая версия закрывает стойку «фото на документы». Журнала выручки, съёмки с камеры и готовой формы ведомств в ней нет.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -e .
.venv/bin/photofordocs
```

Нужен Python 3.11 или новее. Linux, Windows и macOS. Лицо ищется моделью YuNet из OpenCV Zoo, файл лежит в программе и наружу не отправляется.

Открыть снимок — `Ctrl+O`. Сохранить один файл — `Ctrl+E`. Сохранить лист — `Ctrl+S`. Печать — кнопка «Печатать лист». Кадр двигается мышью.

Свой формат записывается в `~/.config/photofordocs/formats/`.

## Проверка

```bash
.venv/bin/python -m unittest discover -s tests
```

Размеры в каталоге — рабочие ориентиры по открытым требованиям к бланкам: паспорта, визы, удостоверения, 3×4 и другие обычные салонные кадры. Перед печатью редкой формы сверьте размер: его можно поправить своим форматом.
