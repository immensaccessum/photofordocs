# Фото для документов

Бесплатная программа для фотосалона и копицентра. Окно собрано как привычное рабочее место: слева снимки, в центре исходник с рамкой, справа формат и коррекция. Сверху три шага — «Размеры», «Готовые фотографии», «Печать». Снимок остаётся на этом компьютера.

Первая версия закрывает стойку «фото на документы». Журнала выручки, съёмки с камеры и готовой формы ведомств в ней нет.

## Независимость и перенос настроек

Это самостоятельный open-source проект. Интерфейс и привычные шаги салона опираются на общий опыт «фото на документы», но программа **ни с кем не аффилирована**: это не официальный продукт, форк и не заявленная замена чужим коммерческим пакетам.

В меню **Сервис → Перенос настроек…** можно сохранить или восстановить выбранные части конфигурации. Читаются только **файлы, которые вы сами указываете** (архив `*.phs`, справочник `*.ini` и т.п.) — чтобы перенести **своё** рабочее место, а не раздавать чужие установки, лицензии, пакеты одежды или готовые каталоги форматов.

Код проекта распространяется под [MIT](LICENSE). Текст README не заменяет консультацию юриста; при коммерческом использовании разумно свериться со специалистом по ИС.

## Каталог форматов

**Новый салон.** В программе есть стартовый набор из десяти частых форматов (`src/photofordocs/formats/*.yaml`, tier `core`). Готовые кадры сохраняются в папке `Ready` как `снимок.<id_формата>.jpg` рядом с файлом `.info`. Свои шаблоны можно добавить в редакторе форматов.

**Перенос со сторонней программы.** Справочник и настройки переносятся через **Сервис → Перенос настроек…** в профиль `~/.config/photofordocs/formats/` (на Windows — в каталоге профиля). Чужие каталоги на диске не изменяются. Старые имена в `Ready` (`*.jp_41`, хвост `~p`) по-прежнему читаются; при наличии формата в профиле с тем же расширением используется он, иначе — сопоставление по `legacy_ext` стартового набора.

Редкие шаблоны программа **не поставляет**: их добавляют вручную в справочнике или импортом (PHS/INI). Перед печатью нестандартного бланка сверьте актуальные требования ведомства.

На Windows, если установлен сторонний справочник форматов, программа **может** подхватить из него только названия и размеры по расширению файла для подписи в дереве снимков. В дистрибутив эти данные не входят.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -e .
.venv/bin/photofordocs
```

Нужен Python 3.11 или новее. Linux, Windows и macOS. Лицо ищется моделью YuNet из OpenCV Zoo, файл лежит в программе и наружу не отправляется.

Открыть снимок — `Ctrl+O`. Сохранить один файл — `Ctrl+E`. Сохранить лист — `Ctrl+S`. Печать — кнопка «Печатать лист». Кадр двигается мышью.

## Проверка

```bash
.venv/bin/python -m unittest discover -s tests
```

Тест `test_real_transfer_file` в `tests/test_phs.py` опционален: он читает локальный файл `оригинал/*.phs`, если вы положили его у себя для проверки. В публичном клоне папка `оригинал/` не нужна — тест сам пропускается.
